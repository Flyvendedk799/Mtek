One motion, different proportions

Original CesiumMan geometry and a generated longer-leg variant share a validated clip mapping. Both combine locomotion, an upper-body action, additive motion, procedural pelvis control, foot planting and a two-hand prop grip.

The host owns actor and prop transforms. The raised track is 15 cm high; ankle targets include each mesh’s sole offset. Root travel has a separate trajectory node so the pelvis can adapt independently. Reset returns actors to their starting positions.


UpperAction, Nod, Idle, Run and Travel are labelled generated demo motions; Walk retains the original animation. See the README for mapping, licences, operating bounds and reproduction.
